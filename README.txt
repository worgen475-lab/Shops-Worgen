GOLDEN GIFTS SHOP
=================

Files:
- index.html: the complete static website
- images/: your four uploaded gift images

How to use:
1. Keep index.html and the images folder together.
2. Open index.html in a browser to preview locally.
3. To publish on GitHub Pages, upload index.html and the images folder to the repository root, then enable Pages from Settings > Pages.

The site is a gift gallery with a poster-style hero and clickable gift detail popups. It does not process payments or automatically send orders.
